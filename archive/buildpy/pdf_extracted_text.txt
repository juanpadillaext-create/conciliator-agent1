2  URLs  
 Alcance  Método  Endpoint  
Obtener  listado  de  documentos  recibidos  
GET  https://services.axteroid.com/rec-docs    
Obtener  listado  de  documentos  pendientes  de  recibir  
GET  https://services.axteroid.com/rec-docs/woemail   
Consultar  xml  documento  
GET  https://services.axteroid.com/rec-docs/{ID_Doc}?format=xml   Nota:  Aplica  solo  para  documentos  recibidos  
Consultar  pdf  documento  
GET  https://services.axteroid.com/rec-docs/{ID_Doc}?format=pdf   Nota:  Aplica  solo  para  documentos  recibidos

3  Autenticación  
 La  autenticación  es  con  un  token  bearer.   CURL  de  ejemplo    curl  --location  'https://services.axteroid..com/' \  --header  'x-ax-workspace:  acc_v7kPkmAnLLOMoq' \  --header  'Authorization:  {token  entregado  por  cliente}' \  --data ''   
4  Parámetros  de  consulta  
 Parámetro  Tipo  Descripción  
created__gte
 string  
Fecha  mínima  de  creación  en  formato  ISO  8601  (YYYY-MM-DDTHH:MM:SS±HH:MM).
 
created__lte
 string  
Fecha  máxima  de  creación  en  formato  ISO  8601  (YYYY-MM-DDTHH:MM:SS±HH:MM).
 
type
 string  
Código  del  tipo  de  documento  a  filtrar  (ejemplo:  CL33).
 
approved  bool  
Indica  si  se  filtran  solo  documentos  aprobados  (true  o  false).
 
page_size  int  
Cantidad  máxima  de  documentos  devueltos  por  página.
 
test  bool  
true:  Prueba  false:  Producción
